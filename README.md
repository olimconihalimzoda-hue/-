# EV Diag 0.2: диагностика электромобилей и проверка батареи (Android)

Приложение на Kotlin и Jetpack Compose. Работает через адаптер ELM327 (Bluetooth или Wi-Fi). Есть симулятор, поэтому интерфейс можно проверить без автомобиля.

## Что умеет

- **Подключение:** Bluetooth (спаренный ELM327), Wi-Fi (192.168.0.10:35000), симулятор. Чтение VIN и подсказка подходящего профиля.
- **Диагностика:** коды ошибок (OBD-II 03/07/0A и UDS 19 02), сброс с подтверждением, батарея со шкалой заряда и диаграммой ячеек, живые параметры с графиками, запись сессии (заряд или поездка) с оценкой ёмкости и экспортом в CSV.
- **Проверка перед покупкой:** одна кнопка читает ошибки и батарею, показывает «светофор» (зелёный, жёлтый, красный) с расшифровкой и создаёт PDF-отчёт: шапка с вашим именем, компанией, телефоном и логотипом, QR-код с контрольной суммой, диаграмма ячеек, итоговый вердикт. Отчёт отправляется в Telegram, WhatsApp и т.д. кнопкой «Поделиться».
- **История:** все проверки, выручка, средний SOH, экспорт в CSV.
- **Мастер сбора данных:** опрашивает машину только на чтение и сохраняет лог. По логу создаётся профиль батареи для новой модели.
- **Профили:** обновление из интернета (папка в вашем GitHub) и импорт из файла без пересборки приложения. Из профилей принимаются только команды чтения: запись, сброс и сервисные сессии отбрасываются.
- **Бренд:** иконка приложения, тёмная и светлая тема.

## Важные ограничения

- Приложение не запускалось на реальном автомобиле. Логика (разбор кадров, формулы, светофор, защита команд) покрыта unit-тестами, интерфейс проверен только на симуляторе.
- **Данных батареи (SOH, ячейки) для реальных моделей пока нет:** в профилях Leaf, Kia/Hyundai, Zoe, VW ID, китайских EV заполнены адреса блоков, но не формулы. Рабочие поля есть только в демо-профиле (вымышленные данные) и в общем профиле OBD-II. Без профиля светофор показывает «Недостаточно данных».
- Пороги светофора ориентировочные (SOH 90/80, разброс ячеек 30/80 мВ), это не нормы производителей.
- Tesla через обычный OBD-разъём данные батареи не отдаёт.
- Дешёвые клоны ELM327 могут работать нестабильно. Лучше OBDLink, vLinker.

## Как создать профиль для новой машины

1. Подключитесь к машине и откройте «Проверка» → «Сбор данных» → «Запустить сбор».
2. Нажмите «Поделиться логом» и отправьте файл разработчику (в файл попадёт VIN).
3. По логу составляется JSON-профиль. Образец: `app/src/main/assets/profiles/demo_ev.json`.
4. Добавьте профиль в приложение: «Ещё» → «Профили автомобилей» → «Выбрать файл». Либо положите его в папку `profiles` своего репозитория и нажмите «Обновить профили».

### Поля профиля

`role` задаёт смысл поля: `soc`, `soh`, `packV`, `current`, `temp`, `cells`. По ролям работают светофор, шкала заряда и оценка ёмкости. Дополнительно: `nominalKwh` (номинальная ёмкость, кВт·ч) и `currentSign` (1: положительный ток означает заряд, -1: наоборот).

Формулы: `b(n)`, `s8(n)`, `u16(n)`, `s16(n)`, `u24(n)`, переменная `i` для массивов (`"repeat": 96, "expr": "u16(10+i*2)/1000"`). Индексы считаются от начала ответа (нулевой байт: SID ответа).

## Обновление профилей из интернета

В репозитории GitHub создайте папку `profiles`. В ней:

- `index.json` вида `{"files": ["kia_niro.json", "byd_atto3.json"]}`
- сами файлы профилей

В приложении: «Ещё» → «Профили автомобилей», в поле укажите адрес папки, например `https://raw.githubusercontent.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ/main/profiles/`, и нажмите «Обновить профили». Шаблон `index.json` лежит в папке `profiles-repo-template/`.

## Сборка без Android Studio (с телефона)

Сборка идёт в облаке GitHub: файл `.github/workflows/build.yml` собирает APK, скачать его можно на вкладке Actions в разделе Artifacts (`ev-diag-apk`).

### Установка обновления

Начиная с версии 0.2 приложение подписывается постоянным ключом, поэтому новые версии ставятся поверх старой.

**Единственный раз** придётся удалить версию, установленную до 0.2: у неё другая подпись, и Android откажется обновлять приложение. История проверок при удалении стирается, поэтому предварительно экспортируйте её в CSV.

## Структура

```
app/src/main/
  AndroidManifest.xml, res/ (иконка, темы, FileProvider)
  assets/profiles/*.json        профили автомобилей
  java/com/evdiag/
    transport/  Bluetooth, Wi-Fi, симулятор
    obd/        ELM327, ISO-TP, коды ошибок, мастер сбора данных
    profile/    формулы, загрузка и защита профилей
    domain/     светофор, оценка ёмкости
    data/       история, настройки, «Поделиться»
    report/     PDF-отчёт с QR
    ui/         тема, компоненты, экраны
app/src/test/   unit-тесты (./gradlew test)
```
